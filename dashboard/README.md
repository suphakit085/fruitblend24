# FruitBlend24 Dashboard

Streamlit Dashboard ภาษาไทย สำหรับเปิดนำเสนอกรณีศึกษาและอธิบายระหว่างสัมภาษณ์

## เปิดใช้งาน

ใช้ Python 3.12 ขึ้นไป เปิด Terminal ในโฟลเดอร์ `dashboard` แล้วรัน

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

เปิด http://localhost:8501 ในเบราว์เซอร์

บนเครื่องที่จัดทำงานนี้ มี environment พร้อมใช้แล้ว ดับเบิลคลิก `Start_Dashboard.cmd` แล้วเปิดลิงก์ด้านบน หรือใช้ `run_dashboard.ps1` ในโฟลเดอร์งานหลัก

## หน้าใน Dashboard

- ภาพรวมธุรกิจ — รายได้ กำไร เป้าหมาย และต้นทุน เลือกช่วงเดือนได้
- เมนูและครัว — กำไรตลอดช่วงข้อมูล และรายการที่ควรตรวจใน 6 เดือนล่าสุด
- ราคาและโปรโมชัน — จำลองราคาและจำนวนแก้ว พร้อมผล matched comparison
- แผน 3 เดือน — เปรียบเทียบ 4 สมมติฐาน และเป้าพร้อมขายกรณีฐานรายครัว/เมนู
- ข้อมูลและวิธีคิด — นิยาม ที่มา และข้อจำกัด

## ข้อมูล

`data/FruitBlend24_Analysis_Results.xlsx` เป็นสำเนาผลวิเคราะห์รุ่นหลักจาก `outputs/FruitBlend24_Analysis_Results.xlsx` ไม่อ่านหรือแก้ Raw

ผลจริง ก.ย. 2025 – ส.ค. 2026 และประมาณการ ก.ย. – พ.ย. 2026 ทั้งหมดเป็นข้อมูลจำลองจากแบบทดสอบ ไม่มีการเชื่อมข้อมูลสด

อัปเดตโดยรัน Notebook หลักและตรวจยอดก่อนแทนที่ไฟล์ใน `data` ระบบอ่านใหม่เมื่อไฟล์เปลี่ยน

## โครงสร้างโค้ด

- `app.py` จัดหน้า ตัวกรอง และกราฟ
- `data_model.py` อ่าน Excel ตรวจยอด และคำนวณสถานการณ์ราคา
- `styles.css` รูปแบบหน้าจอ
- `.streamlit/config.toml` ธีมและการรันในเครื่อง

ไม่ต้องใช้ API key หรือบัญชีบริการอื่น การเผยแพร่ให้คนอื่นเปิดผ่านอินเทอร์เน็ตต้องตั้งโฮสต์เพิ่มเติม

## ตรวจการทำงาน

```powershell
python check_dashboard.py
```

ตรวจยอดรายได้และกำไรเทียบผลวิเคราะห์ ตัวกรองเดือน/เมนู/ครัว/สต็อก การจำลองราคา จุดคุ้มทุน และทั้ง 4 สมมติฐาน พร้อมรันกราฟและตารางครบทุกหน้า
